# RESCA IMMOBILIARE

Landing page ufficiale ad alta conversione per **RESCA IMMOBILIARE**, agenzia specializzata nell'intermediazione, stima e compravendita di immobili residenziali e commerciali di pregio.

## 🚀 Caratteristiche del Progetto
- **Design Moderno & Reattivo**: Costruito con HTML5 semantico e Vanilla CSS personalizzato (palette arancione/bianco/antracite).
- **Vetrina Immobili di Pregio**: Schede dettagliate con modali interattive per consultare specifiche e planimetrie.
- **Valutatore Interattivo Immobile**: Step-by-step estimator con calcolo del valore in tempo reale basato su tipologia e metratura.
- **Form di Contatto Ottimizzati**: Feedback visivo immediato tramite notifiche toast interattive.
- **Mobile First**: Ottimizzato per smartphone e tablet con barra di contatto rapido (chiamata e WhatsApp).
